# Iran Kill Switch — راهنمای فارسی (نسخه‌ی ۲)

- **سایت‌های ایرانی:** مستقیم.
- **سایت‌های خارجی:** فقط از داخل VPN.
- **اگر VPN قطع یا بسته شود:** ترافیک خارجی با IP واقعی بیرون نمی‌رود و سایت‌های ایرانی کار می‌کنند.
- **با هر VPNی کار می‌کند**، بدون هیچ تنظیمی در خود VPN: Hiddify، v2rayN، Clash، AmneziaVPN، AmneziaWG، WireGuard، تونل SSH با MobaXterm، BlueStacks و غیره.

---

## نصب
فایل **`IranKillSwitch-Setup-x.y.z.exe`** را اجرا کنید و پیام UAC را تأیید کنید.
- **به‌روزرسانی:** نسخه‌ی جدید را همین‌طور اجرا کنید. تنظیمات حفظ می‌شود.
- **نصب بی‌صدا** (برای چند سیستم): `IranKillSwitch-Setup-x.y.z.exe /quiet`
- اگر پیام «Windows protected your PC» آمد: **More info ← Run anyway**. این پیام فقط به این دلیل است که فایل امضای دیجیتال ندارد.

## استفاده
1. برنامه را از دسکتاپ یا منوی Start باز کنید.
2. روی **حلقه‌ی بزرگ** کلیک کنید (روشن/خاموش با همین حلقه است؛ با کیبورد: Tab و Enter).
3. برنامه خودش تست می‌گیرد. اگر همه‌چیز درست بود، **Keep protection** را بزنید.
   اگر ظرف ۲ دقیقه تأیید نکنید، همه‌چیز **خودکار برمی‌گردد**.
- **حلقه‌ی بزرگ** فقط وضعیت را نشان می‌دهد: سبز یعنی محافظت روشن، خاکستری یعنی خاموش.
- **دکمه‌ی X** برنامه را به کنار ساعت (System Tray) می‌برد. محافظت حتی با بستن برنامه هم کار می‌کند.

| بخش | کار |
|---|---|
| **VPN apps ← Manage** | دیدن، اضافه کردن (**Add app**) یا حذف برنامه‌های VPN |
| **Iran direct (TUN)** | برای VPNهای حالت TUN: سایت‌های ایرانی از اینترنت معمولی بروند |
| **Leak test** | تست نشتی: ترافیک خارجی بدون VPN، DNS، WebRTC، IPv6 و سایت‌های ایرانی |
| **Preview** | نشان می‌دهد روشن کردن چه کاری می‌کند، بدون اعمال هیچ تغییری |
| **Refresh** | پیدا کردن VPNهای تازه نصب‌شده، به‌روزرسانی لیست ایران و اعمال دوباره‌ی Direct sites |
| **Direct sites** | لیست سایت‌های خارجی که بدون VPN باز شوند؛ هر خط یک دامنه، آدرس، IP یا CIDR. ذخیره کنید و Notepad را ببندید. در حالت TUN و System Proxy کار می‌کند |
| **Allowed servers** | (اختیاری) برای VPN داخلی ویندوز یا SOCKS5 که مستقیم در مرورگر تنظیم شده |

**اگر VPN شما وصل نشد:**
1. VPN را باز کنید و در برنامه **Refresh** بزنید.
2. اگر باز هم وصل نشد: **Manage ← Add app** و فایل exe آن VPN را انتخاب کنید.

برنامه‌هایی که یک VPN مجاز خودش اجرا کند (مثل `MobaRTE.exe` در MobaXterm) خودکار مجاز می‌شوند.

## شرایط
- ویندوز ۱۰ (نسخه‌ی 1607 به بعد) یا ۱۱؛ Home یا Pro؛ ۳۲ یا ۶۴ بیتی.
- دسترسی Administrator.
- **نیازی به نصب برنامه‌ی دیگری نیست.**
- به فایروال ویندوز دست نمی‌زند.

## برگرداندن و حذف
| کار | روش |
|---|---|
| خاموش کردن | کلیک روی **حلقه‌ی بزرگ** |
| اضطراری، حتی اگر برنامه خراب باشد | Start ← Iran Kill Switch ← **Emergency OFF** |
| حذف کامل | Settings ← Apps ← Iran Kill Switch، یا **Uninstall** پایین برنامه |

## تست دستی
1. محافظت روشن و VPN وصل باشد. یک سایت خارجی و یک سایت ایرانی باید باز شوند.
2. VPN را کامل ببندید:
   - سایت خارجی باید **باز نشود**؛
   - سایت ایرانی باید **باز شود**.
3. **ipmyp.ir** (ایرانی) باید IP واقعی شما را نشان دهد.
4. **ipleak.net** (خارجی، با VPN) باید IP سرور VPN را نشان دهد.
5. نشت WebRTC را با **browserleaks.com/webrtc** و DNS را با **dnsleaktest.com** بررسی کنید.

## محدودیت‌ها
- ترافیک **WSL2 یا Hyper-V** از قانون‌ها عبور نمی‌کند.
- VPNهایی که Kill Switch داخلی دارند (مثل WireGuard با «Block untunneled traffic») مسیر مستقیم ایران را هم می‌بندند. آن گزینه را خاموش کنید؛ Kill Switch این ابزار جایش را می‌گیرد.
- **VPN اندرویدی داخل BlueStacks:** Kill Switch برایش کار می‌کند، ولی مسیر مستقیم ایران باید در خود آن VPN تنظیم شود.
